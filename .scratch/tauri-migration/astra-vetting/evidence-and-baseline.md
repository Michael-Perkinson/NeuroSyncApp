## External claims checked against primary documentation

These are documentation findings, not successful build results. Sources were checked during this review; toolchains must be pinned when implementation begins.

- Tauri `externalBin` requires target-suffixed executables. Use `x86_64-pc-windows-msvc`, `aarch64-apple-darwin`, and `x86_64-apple-darwin`, with `.exe` on Windows. The documentation demonstrates Rust-owned stdio, not a mandated JSON-RPC standard. [Tauri sidecars](https://v2.tauri.app/develop/sidecar/).
- PyInstaller onedir contains an executable **and its dependencies**. Inference: listing only that executable in externalBin does not prove its complete directory layout survives bundling. Onefile extracts dependencies at startup and can leave its extraction folder after a kill. [PyInstaller operating modes](https://pyinstaller.org/en/stable/operating-mode.html).
- `uv build` builds source distributions and wheels. Reject the proposed `uv build --standalone` executable-packaging command in assumptions:50 unless a separate, real packaging mechanism is specified and proven. [uv command reference](https://docs.astral.sh/uv/reference/cli/#uv-build).
- Tauri offers an offline WebView2 installer mode and fixed-runtime distribution. A normal bootstrapper is not enough for a clean disconnected Windows installation. [Tauri Windows installers](https://v2.tauri.app/distribute/windows-installer/#offline-installer).
- Tauri capabilities do not make custom Rust code, incorrect scope checks, or arbitrary Python reads safe automatically. The host/sidecar interface needs its own path authorization. [Tauri capabilities](https://v2.tauri.app/security/capabilities/).
- Native app testing must be selected deliberately. Current Tauri docs describe WebdriverIO's embedded server on Windows/Linux/macOS; direct tauri-driver supports Windows/Linux. Do not claim macOS automation is categorically impossible, or equate a browser Playwright test with installed-app validation. Keep test servers out of production packages. [Tauri WebDriver testing](https://v2.tauri.app/develop/tests/webdriver/).
- Signing/notarization configuration needs platform-specific validation of the final artifact, including the Python payload. Credential selection is an implementation/release dependency. [Tauri macOS signing](https://v2.tauri.app/distribute/sign/macos/).
